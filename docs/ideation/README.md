# eos-seed — Ideation Garden

This folder holds the fleet's *thinking* about eos-seed, kept separate from the
built artifact so a developer can see the full trail — including dead ends and
kills — not just the code.

## For the builder (start here)
- **`../NMEA-REPLAY-SPEC.md`** — the next build: sign-pyramid frames + pre-registered kill criteria. This is the concrete "what to code next."
- **`../LEDGER.md`** — the quantizer/learning lessons booked so far (failures first-class).

## Ideation (why, not how)
- **`first-feed-round.md`** — the 3-model wide round on which feed eOS breathes first (boat/bar/adversary) + synthesis. The adversary lane's pre-registered kill criteria became NMEA-REPLAY-SPEC.
- **`eos-the-hold.md`** — lore: "Eos, the Hold" — the substrate given a voice in fleet cosmology (also in AI-Writings/short-stories).

Rule of this folder: ideation that produces a build gets a pointer *into* the build; ideation that dies gets archived with its kill reason. Nothing is deleted.
